# Maulam Safnan Trading & Co. L.L.C. — Website

Bilingual (English / العربية) sales website for **Maulam Safnan Trading & Co. L.L.C.** (معالم صفنان للتجارة والمقاولات), a trading and contracting company registered in the Sultanate of Oman.

## Features
- Full-screen hero with clear calls to action
- Six service cards with photos and "Get a quote" links that preselect the service in the form
- Supply + install value section, 5-step process, sectors served, FAQ
- Quotation form that opens WhatsApp with the client's details pre-filled
- Floating WhatsApp button and a mobile Call / WhatsApp action bar
- English / Arabic switch with full right-to-left layout
- SEO meta tags and LocalBusiness structured data

## Files
- `index.html` — the whole site (no build step)
- `assets/logo.svg` — vector recreation of the company logo
